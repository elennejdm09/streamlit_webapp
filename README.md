## 📖 Overview

**Data Engineer RPG** (also known as QuestList) is a gamified task management and learning tracker built entirely in Python using Streamlit. Designed to make the journey into Data and AI Engineering more engaging, this application transforms standard study goals and project milestones into an interactive Role-Playing Game. 

Users can log "quests" (tasks, tutorials, or coding challenges), earn Experience Points (XP) upon completion, and visualize their progression as they level up their technical skills.

## ✨ Key Features

*   **Gamified Task Management (CRUD):** Create, read, update, and delete daily tasks framed as "Quests."
*   **XP & Leveling System:** Earn experience points by completing quests to level up your character profile.
*   **Skill Categorization:** Tag quests by specific data engineering domains (e.g., Python, SQL, Cloud Architecture, Data Pipelines).
*   **Progress Dashboard:** Interactive visualizations to track completed quests and skill growth over time.
*   **Persistent State:** Utilizes Streamlit's session state to manage and maintain user data during the active session.

## 🛠️ Tech Stack

*   **Frontend & UI:** [Streamlit](https://streamlit.io/)
*   **Language:** Python
*   **Data Handling:** Pandas (for structuring quest data and metrics)
*   **Development Workflow:** AI-Assisted Prompt Engineering

## 🧠 AI-Assisted Development

This approach demonstrates proficiency in leveraging modern AI tools to accelerate the software development lifecycle, translate conceptual requirements into functional Python code, and debug efficiently.
